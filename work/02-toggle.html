02 — Product Design · 2024

Toggle SaaS

업무 흐름이 보이는 홈 화면 리디자인

홈 화면 평균 체류시간이 3초 미만이라는 문제에서 출발해, 통합 검색 중심의 첫 화면을 프로젝트 단위 업무 허브로 재설계했습니다. 칸반 기반 정보 구조를 통해 사용자가 홈에서 업무 현황을 파악하고, 서비스의 핵심 가치를 더 빠르게 체감하도록 설계했습니다.

Role Product Designer

01 Context

왜 홈 화면을 다시 설계했는가

Toggle은 Gmail, Slack, Notion 등 여러 업무 툴에 흩어진 정보를 하나의 플랫폼에서 통합 관리할 수 있는 B2B SaaS 서비스입니다. 시드 투자 유치 이후 서비스 성장 단계에서, 핵심 진입 화면인 홈의 평균 체류시간이 3초 미만으로 낮게 나타나는 문제가 있었습니다.

기존 홈 화면은 통합 검색 기능에 집중된 구조였습니다. 사용자가 로그인 후 가장 먼저 접속하는 화면임에도, 업무 흐름을 파악하거나 프로젝트 단위로 정보를 확인하려면 다른 기능 화면으로 이동해야 했습니다.

이 프로젝트는 외부 디자이너 8인이 각자 독립적인 솔루션을 제안하고, 상호 피드백을 통해 방향성을 고도화하는 스프린트 방식으로 진행되었습니다.

02 Problem

홈이 서비스 가치를 전달하지 못하고 있었다

홈 화면의 평균 체류시간이 3초 미만이라는 수치는 단순히 사용자가 화면에 오래 머물지 않는다는 의미가 아니었습니다. 사용자가 로그인 후 서비스의 핵심 가치인 '분산된 업무 정보의 통합 관리'를 충분히 경험하지 못하고 있다는 신호였습니다.

기존 홈은 검색 외에 활용할 수 있는 정보 구조가 부족했고, 사용자는 업무 현황을 파악하기 위해 각 기능 화면으로 이동해야 했습니다. 그 결과 홈 화면은 서비스의 시작점임에도 불구하고, 업무를 이어가는 허브로 작동하지 못했습니다.

  • 문제 1
    낮은 체류시간 — 홈 화면 평균 체류시간 3초 미만. 통합 검색 외에 사용자가 머물며 탐색할 수 있는 인터페이스가 부족했습니다.
  • 문제 2
    기능 화면으로의 빠른 이탈 — 업무 흐름을 확인하려면 각 기능 페이지로 이동해야 했고, 홈은 전체 현황을 파악하는 역할을 하지 못했습니다.
  • 문제 3
    서비스 가치 체감 부족 — 연동된 업무 툴의 데이터를 홈에서 바로 활용하기 어려워, '효율적인 업무 관리'라는 핵심 가치가 충분히 전달되지 않았습니다.
03 Decision

홈의 역할을 '검색 진입점'에서 '업무 허브'로 전환

핵심 판단은 통합 검색 기능을 제거하는 것이 아니라, 홈 화면의 역할을 재정의하는 것이었습니다. 기존 홈이 검색을 시작하는 화면이었다면, 개선안에서는 사용자가 업무 현황을 바로 파악하고 다음 행동으로 이어질 수 있는 업무 허브가 되어야 한다고 판단했습니다.

이를 위해 홈 화면 체류시간 6초 이상을 Target Metric으로 설정하고, 리텐션 개선이라는 비즈니스 목표를 정보 구조 설계의 기준으로 연결했습니다.

  • 한 것
    프로젝트 단위로 업무 데이터를 재분류하고, 칸반보드 기반 홈 화면으로 재설계했습니다. 연동된 SaaS 데이터가 홈 진입 즉시 보이도록 구조를 전환했습니다.
  • 하지 않은 것
    각 기능 페이지 전체를 재설계하지 않았습니다. 홈이 모든 기능을 담으려 하기보다, 사용자가 업무 흐름을 빠르게 파악하는 데 집중했습니다.
  • 설계 기준
    사용자에게 익숙한 칸반 인터랙션을 활용해 학습 비용을 줄이고, 드래그앤드롭과 업무 추가 버튼을 함께 제공해 진입 경로를 이중화했습니다.
04 Design

솔루션 — 업무 흐름이 보이는 홈

개선된 홈 화면은 프로젝트 단위로 업무 정보를 재구성해, 사용자가 다른 화면으로 이동하지 않아도 현재 업무 현황을 파악할 수 있도록 설계했습니다.

D-Day / 진행 상태

마감일과 진척도 직접 노출

마감일과 진행률을 카드에 직접 노출해, 사용자가 우선순위 판단에 필요한 핵심 정보를 한눈에 확인할 수 있도록 했습니다.

프로젝트 수가 많아질수록 홈 화면의 정보 밀도가 높아질 수 있다고 판단했습니다. 정렬과 필터 기준을 분리해 설계했습니다.

정렬 / 필터 구성안 이미지 준비 중

최초 로그인 시 앱 연동이 완료되지 않으면 서비스 활용이 제한될 수 있기 때문에, 온보딩 팝업을 통해 연동 과정과 주요 기능 학습을 자연스럽게 유도했습니다.

온보딩 팝업 — 최초 로그인 시 연동 및 기능 학습 유도 이미지 준비 중
