01 / Product Design

국내 1위 MTS앱
신규 퇴직연금 기능 구축

복잡한 기존 디자인 스타일 개선 및 사용자의 편리한 퇴직연금 서비스 이용을 위한 화면 디자인.
3종 혼재 가이드를 Type 1 기반으로 통합하고 1,800페이지 규모 라이트·다크 토큰화를 주도.

Role Design PL
(UI·UX 디자인, 디자인 시스템 및 신규 가이드 제안)
Duration 2025.05 — 2026.02
Collaboration 담당 현업, 기획팀, 디자인팀,
퍼블리싱 및 개발 전문 회사
Tools Figma, ChatGPT, Photoshop
🔒

본 프로젝트는 미출시 서비스로, 일부 화면은 NDA에 의해 공개가 제한됩니다.
As-is 화면 및 일부 To-be 상세 화면은 블러 처리 또는 생략되어 있습니다.

01 — Context

왜 이 프로젝트를 했는가

국내 증권사 앱 중 고객 사용량 1위의 MTS로, 다양한 기능이 누적되며 디자인 가이드가 혼재된 상태에서 퇴직연금 신규 기능 개발 프로젝트를 사용자 혼란을 최소화하는 것을 목표로 진행했습니다.

기존 퍼블리싱·개발 환경을 고려해 일정 내에 수행 가능한 현실적인 디자인 작업 방식과 일관된 디자인 규칙, 퇴직연금 전용 이미지 스타일을 정의했습니다.

02 — Problem

문제의 크기

기존에 혼재되어 있던 복수의 디자인 가이드와 스타일을 분석하고, 프로젝트 진행에 가장 적합한 기준을 선별하여 디자인 방향성을 재정의했습니다.

Target User

투자 경험은 있으나, 퇴직연금 구조와 용어에 대한 이해가 낮아 복잡한 정보 속에서 의사결정에 어려움을 겪는 사용자

01
Problems

UI 불일치로 인한 사용자 혼란
개발 방식과 디자인 가이드가 혼재되어 서비스 내 일관되지 않은 경험과 높은 이탈 가능성 발생


구조적 제약으로 인한 확장성 한계
as-is 유지 환경에서 부분적 개선만 가능해 정보 구조와 인터페이스 일관성 유지가 어려운 상태

02
Target Metric

복잡한 정보 구조로 낮아진 사용자 이해도와 의사결정 효율 개선을 핵심 목표로 설정. 가독성과 정보 계층을 사용자 중심으로 재정의해 핵심 정보를 빠르게 파악할 수 있는 경험 제공. 사용자 흐름을 안정화하고 이탈 가능성을 최소화

03
03 — Decision

무엇을 하고, 무엇을 하지 않았는가

혼재된 레거시 가이드 환경에서의 디자인 시스템 재정립

3종 이상의 가이드가 혼재된 상황에서, 타이트한 일정과 제약된 상황 속 Type 1 기반 통합 가이드를 재정의하여 서비스 일관성과 확장성을 확보했습니다.

한 것

Type 1 기반 선택으로 전 서비스에 가장 빠르고 안정적으로 적용. Figma 도입으로 실시간 협업 효율 대폭 향상. 불필요한 재작업 최소화 및 향후 Type 2 병합 시 유연한 확장성 확보

하지 않은 것

Type 2 미완성, 파일 수급 제약, 중간 소통 미흡, 내부 운영·개발환경 제약으로 일정 내 현실적인 방안의 통합이 가장 큰 과제였기에, 완전한 Type 2 병합은 단계적으로 미룸

기준

기존 퍼블리싱·개발 환경을 고려한 현실적 적용 가능성과 서비스 전반의 일관성 확보를 동시에 달성할 수 있는 최소 공통 기반 선택

04 — Design

주요 개선 화면

복잡한 정보를 더 쉽게 볼 수 있게

Type 1 가이드 적용으로 상품 정보를 정보 계층과 컬러 계층으로 정리, 사용자가 핵심을 빠르게 파악할 수 있도록 개선했습니다.

일관된 디자인 기준 적용

퇴직연금 기능 전반에 통합 디자인 기준 적용 완료

협업 효율 대폭 향상

Figma 전환으로 개발 QA 실시간 소통 대폭 강화

확장성 기반 마련

향후 신규 기능 및 Type 2 병합 시 재작업 최소화

기존 화면은 NDA로 인해 공개가 어렵습니다

데이터 시각화 중심

복잡한 수익률·위험도 정보를 시각적 선명도, Semantic Color, 직관적 그래프로 재구성하여 사용자 이해도를 높였습니다. 용어와 숫자가 많은 영역에서 "보여주기"보다 "이해시키기"에 집중한 개선입니다.

시각적 선명도 향상

정보 밀도 낮추고 그리드 시스템 체계 적용

컬러 계층 재정의

성공/위험/중립 색상 명확 구분 + 고연령 가독성 고려

그래프 및 데이터 표현 최적화

복잡한 수익률 기간 비교를 직관적 차트로 전환

운영 효율화 — AI 활용 3D 아이콘 및 배너 이미지 제작

기존 이미지 파일 용량 과다, 제작 시간 소요, 낡은 시각으로 인한 사용자 거리감 문제를 AI 프롬프트 엔지니어링으로 퇴직연금 컨셉에 맞는 친근한 3D 스타일로 개선했습니다.

문제 인식

기존 이미지 파일 용량 과다, 제작 시간 소요, 낡은 시각으로 인한 사용자 거리감

접근 방식

AI 프롬프트 엔지니어링으로 퇴직연금 컨셉에 맞는 친근한 3D 스타일 생성

주요 성과

파일 용량 대폭 감소 + 작업 시간 단축 + 트렌디한 3D 표현으로 사용자 친근감 및 이해도 향상

AI 도구를 단순 이미지 생성이 아닌, 운영 효율과 사용자 경험 향상이라는 비즈니스 가치로 연결

라이트 / 다크 모드 토큰화 작업

1,800페이지 이상의 대규모 화면 작업에서 Figma Variables와 토큰화를 활용해 라이트·다크 모드를 효율적으로 구축하고, 유지보수성을 극대화했습니다.

대규모 작업 효율화

Figma Variables 토큰화로 1,800페이지 라이트·다크 모드 동시 구축

디자인 시스템 실전 적용

XD·Photoshop 환경에서 Figma 전환 후 체계적인 컴포넌트 관리

확장성과 유지보수성 강화

단일 토큰으로 모드 전환 가능, 향후 테마 변경 시 최소 수정

타이트한 일정 속 대규모 작업에서 디자인 시스템 Variables를 실전 적용해 효율성과 확장성을 동시에 확보

06 — Review

회고

What Changed
: 성과

01
서비스 전반 디자인 일관성 확보

3종 혼재 가이드를 Type 1 기반으로 통합하여 타이포그래피·스페이싱·컬러·컴포넌트 규칙을 재정립, 퇴직연금 기능 전반에 일관된 사용자 경험을 구축

02
Figma 기반 협업 체계 전환

XD·Photoshop 혼용 환경에서 Figma Single Source of Truth로 전환 후 Variables 토큰 적용, 1,800페이지 라이트·다크 모드를 동시 구축하고 개발·QA 실시간 소통 체계를 확보

03
AI 활용 운영 효율화

AI 프롬프트 엔지니어링으로 서비스 톤에 맞는 3D 이미지를 직접 제작하여 외주 없이 운영 리소스를 절감하고 브랜드 일관성을 유지

What I'd Do Differently
: 아쉬운 점

01
실사용 데이터 미확보

프로젝트는 설계 완료 및 배포 준비까지 마친 상태로 종료되었으나, 파건 계약 만료로 오픈 이후 검증에는 참여하지 못함. 설계 의도가 실제 사용자 행동에서 유효했는지 검증하지 못해 가설 기반 설계에 머문 것이 가장 큰 아쉬움

02
사용자 리서치 부재

획과 디자인이 동시에 진행되는 일정 구조상 실제 사용자 인터뷰나 사용성 테스트 없이 설계를 시작했고, 데이터와 현장 관찰 기반의 문제 정의가 뒷받침 됐다면 설계 방향의 근거가 더 탄탄했을 것

03
데이터 기반 설계 방어의 한계

외주사 PL로서 클라이언트 내부 탑다운 피드백에 대응하는 과정에서 디자인 근거를 조직 전체에 설득하는 데 한계가 있었고, 이 경험이 인하우스에서 제품의 전체 라이프사이클을 직접 오너십 있게 이끌며 데이터 기반 판단을 실천하고 싶다는 강한 동기로 이어짐
